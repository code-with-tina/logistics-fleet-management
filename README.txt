FLEETFLOW - LOGISTICS & FLEET MANAGEMENT
Requirements: XAMPP, Apache, MySQL, PHP mysqli.
1. Extract this ZIP.
2. Copy the logistics-fleet-management folder into C:\xampp\htdocs\
3. Start Apache and MySQL in XAMPP.
4. Open http://localhost/phpmyadmin
5. Select Import and import database.sql.
6. Open http://localhost/logistics-fleet-management/

Features: Dashboard, vehicle registration, driver directory, trip scheduling, maintenance history and costs.
Demo data: two vehicles and two drivers are inserted automatically.
Database: logistics_fleet. Default XAMPP username root and blank password.
Educational demo only; no live GPS, maps, SMS or payment integration.
